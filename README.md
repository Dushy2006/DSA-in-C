# DSA-in-C
A structured collection of Data Structures and Algorithms in C, starting from recursion and progressing through arrays, strings, linked lists, trees, graphs, and more — built for practice, problem-solving, and strong fundamentals.
This repo also includes categorized lab programs for each topic, ranging from beginner-level (“banana”) to challenging-level (“jackfruit”) problems as part of college practice and self-learning.
